# ProstaVive - Men's Longevity & Cellular Vitality Advertorial

Reporte de investigación biomédica y página advertorial optimizada para la conversión sobre salud celular, microcirculación pélvica y vitalidad masculina después de los 40 años.

## 🚀 Estructura del Proyecto

- `index.html`: Estructura semántica, metadatos SEO, integración de Meta Pixel, diseño editorial en dos columnas, barra de progreso de lectura y modal nativo HTML5 `<dialog>`.
- `styles.css`: Sistema de diseño responsivo con tipografía fluida `clamp()`, paleta clínica (Azul Marino `#1A2B4C`, Verde Botánico `#2D6A4F`, Naranja Coral `#E07A5F`), tarjetas de investigación y micro-animaciones de alta conversión.
- `script.js`: Lógica interactiva en Vanilla JS (barra de lectura superior, gestión modal `<dialog>`, fechas dinámicas de actualización y validación de formulario de captación).
- `assets/images/`: Recursos visuales optimizados para el reporte editorial (`man-tired.jpg`, `man-vital.jpg`).

## 🛠️ Tecnologías

- HTML5 Semántico y Accesibilidad (WAI-ARIA, `<dialog>`)
- Vanilla CSS3 Moderno (Custom Properties, Flexbox, CSS Grid, Fluid Typography)
- JavaScript Vanilla (ES6+, sin dependencias externas)
