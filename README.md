# ProstaVive - Advertorial Vitalidad y Salud Celular

Reporte de investigación biomédica y página advertorial optimizada para la conversión en marketing de afiliados sobre salud celular, energía mitocondrial y vitalidad.

## 🚀 Estructura del Proyecto

- `index.html`: Estructura semántica, metadatos SEO, comparador antes/después interactivo, tabla comparativa clínica, FAQs accesibles y modales de reserva/verificación de stock.
- `styles.css`: Sistema de diseño responsivo con tipografía fluida `clamp()`, paleta clínica (Azul Marino `#1A2B4C`, Verde Botánico `#2D6A4F`, Naranja de Conversión `#E07A5F`) y micro-animaciones CRO.
- `app.js`: Lógica interactiva en Vanilla JS (slider comparativo touch/mouse/teclado, barra de lectura superior, barra sticky flotante, temporizador de reserva de lote y modal de disponibilidad).
- `assets/`: Recursos multimedia y comparativas visuales de casos de estudio.

## 🛠️ Tecnologías

- HTML5 Semántico y Accesibilidad (WAI-ARIA)
- Vanilla CSS3 Moderno (Custom Properties, Flexbox, CSS Grid, Fluid Typography)
- JavaScript Vanilla (ES6+, sin dependencias externas)
